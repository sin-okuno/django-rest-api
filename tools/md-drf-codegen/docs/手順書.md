# md-drf-codegen 手順書

`examples/product.md` を入力として、YAML 抽出 → 検証 → DRF コード自動生成までの手順です。

機能・制約の詳細一覧は [../README.md](../README.md) を参照してください。

## 前提

- 上記「ランタイム」の Python 3.12 以上がインストール済み
- 作業ディレクトリは常に次のパスとします。

```text
django-rest-api/tools/md-drf-codegen
```

---

## 初期状態（本手順の起点）

リポジトリに含まれる入力サンプル:

```text
examples/product.md                    # API 仕様（推奨・新形式）
examples/specs/product-structure.md    # 画面全体仕様（旧形式・互換用）
```

生成物は Git 管理外です（`.gitignore`）。初回実行時に次が自動作成されます。

```text
generated-specs/    # ApiSpec YAML / OpenAPI YAML（openapi 単独時）
generated/          # 生成 Python コード + openapi.yaml（all 時）
```

### 入力 Markdown の形式

| 形式 | ファイル例 | 型定義の主な列 |
| --- | --- | --- |
| 新形式（推奨） | `examples/product.md` | `型名`, `プロパティ`, `型`, `必須`, `Nullable`, `制約`, `エラーメッセージ`, `備考` |
| 旧形式（互換） | `examples/specs/product-structure.md` | `カテゴリー`, `型名`, `プロパティ`, `型`, `任意`, `最大桁数`, `小数桁` |

### 必須・任意セクション

| セクション | 必須 | 用途 |
| --- | --- | --- |
| `## API一覧` | 必須 | エンドポイント（備考列は任意） |
| `## 型定義` | 必須 | リクエスト / レスポンス DTO |
| `## パスパラメータ` | パスに `{name}` があるとき必須 | URL セグメントの形式検証 |
| `## 定数定義一覧` | 任意 | 既存 Enum / 定数クラスの import 元 |

#### 各セクションの列

**API一覧:** `API ID`, `API名`, `メソッド`, `パス`, `リクエスト型`, `レスポンス型`, `備考`（任意）

**パスパラメータ:** `パラメータ名`, `型`, `制約`, `エラーメッセージ`（任意）, `備考`（任意）

**定数定義一覧:** `ファイルパス`, `クラス名`, `備考`（任意）

**型定義:** `型名`, `プロパティ`, `型`, `必須`, `Nullable`, `制約`（任意）, `エラーメッセージ`（任意）, `備考`（任意）

`備考` は ApiSpec YAML に保存され、OpenAPI の `description` に反映されます（`-` / 空欄はなし）。

### 対応型（プリミティブ）

| 型 | Serializer | 入力例 |
| --- | --- | --- |
| `string` | `CharField` | `"ABC"` |
| `integer` | `IntegerField` | `1` |
| `number` | `FloatField` | `1.5` |
| `boolean` | `BooleanField` | `true` |
| `date` | `DateField` | `"2024-01-15"` |
| `datetime` | `DateTimeField` | `"2024-01-15T12:00:00Z"` |
| `object` | `JSONField` | `{...}` |

`date` / `datetime` / `boolean` / `object` の制約列は `-` にしてください。

### Enum の使い方（要約）

1. **既存 Enum を使う（推奨）**  
   `## 定数定義一覧` にファイルパスとクラス名を登録する。

```markdown
## 定数定義一覧

| ファイルパス | クラス名 | 備考 |
| --- | --- | --- |
| common/util/Consts.py | Status | 1:Low / 2:Middle / 3:High |
| common/util/Consts.py | Priority | 1:IM / 2:SH / 3:NO |
```

2. **型定義の制約列に値一覧を書く**（OpenAPI 用。表では `、` 区切り推奨）。

```markdown
| ProductUpdateRequest | status | integer | true | false | enum:1:Low、2:Middle、3:High | - | Status 参照 |
| ProductUpdateRequest | priority | integer | true | false | enum:1:IM、2:SH、3:NO | - | Priority 参照 |
```

3. **紐づけ**  
   - プロパティ名 `status` → クラス名 `Status`（PascalCase）が一覧にあれば import  
   - 名前が違うときは制約に `ref:Priority` を付ける  
   - 一覧に無い場合は Serializer 内にローカル `Enum` を生成

4. **生成コード**（標準 `Enum` 向け）:

```python
from common.util.Consts import Status

status = serializers.ChoiceField(
    choices=[(m.value, m.name) for m in Status],
    ...
)
```

既存定数の例:

```python
from enum import Enum

class Status(Enum):
    HIGH = 1
    MIDDLE = 2
    LOW = 3

class Priority(Enum):
    IM = 1
    SH = 2
    NO = 3
```

詳細（`ref:`、ローカル生成、YAML 表現、注意点）は [README.md の Enum 節](../README.md#enum列挙値の使い方) を参照してください。

### エラーメッセージ列

- 任意。未記載・`-` の場合は DRF 標準メッセージ。
- Enum 不正値は `invalid_choice:メッセージ`。

パス・クエリ・ボディの対応は [README.md](../README.md) の「パスパラメータとクエリパラメータ」を参照してください。

## 1. セットアップ（初回のみ）

```powershell
cd django-rest-api\tools\md-drf-codegen
python -m venv .venv
.\.venv\Scripts\activate
pip install -e ".[dev]"
```

インストール確認:

```powershell
md-drf-codegen --help
python --version    # 3.12 以上であること
pytest --version
ruff --version
```

## 2. Markdown → ApiSpec YAML 抽出

```powershell
md-drf-codegen extract examples\product.md
```

省略時の出力先:

```text
generated-specs/product-api.yaml
```

出力先を明示する場合:

```powershell
md-drf-codegen extract examples\product.md -o generated-specs\product-api.yaml
```

成功時:

```text
Wrote ...\generated-specs\product-api.yaml
```

### 旧形式仕様書から抽出する場合

```powershell
md-drf-codegen extract examples\specs\product-structure.md
```

出力: `generated-specs/product-structure-api.yaml`（`{入力stem}-api.yaml`）

> ApiSpec YAML は DRF 生成用の中間形式です。Swagger にはそのまま使えません。

---

## 3. YAML 検証（推奨）

```powershell
md-drf-codegen validate generated-specs\product-api.yaml
```

成功時:

```text
OK: ...\generated-specs\product-api.yaml
```

参照切れ・パスパラメータ未定義・スキーマ不正があると exit code 1 で失敗します。

## 4. YAML → DRF コード自動生成

```powershell
md-drf-codegen generate generated-specs\product-api.yaml --target all
```

再生成で既存ファイルがある場合:

```powershell
md-drf-codegen generate generated-specs\product-api.yaml --target all --force
```

省略時の出力先（YAML の stem）:

```text
generated/product-api/
```

`build` から実行した場合は **Markdown の stem** が使われます（例: `product.md` → `generated/product/`）。

### `--target` オプション

| 値 | 生成内容 |
| --- | --- |
| `yaml` | ApiSpec YAML のみ（`build` 時） |
| `openapi` | OpenAPI 3.0 YAML のみ |
| `serializer` | Serializer のみ |
| `all` | Serializer / View / URL / パス検証 / テスト / OpenAPI |

### 生成されるファイル（`--target all`）

| ファイル | 内容 |
| --- | --- |
| `<prefix>_serializers.py` | DRF Serializer（Enum import / ChoiceField 含む） |
| `<prefix>_handlers.py` | API ごとの処理関数（初期はデモレスポンス） |
| `<prefix>_path_validators.py` | パスパラメータ形式検証（定義がある場合） |
| `<prefix>_views.py` | APIView（リクエスト検証 → Handler → レスポンス Serializer） |
| `urls.py` | `urlpatterns` |
| `openapi.yaml` | OpenAPI 3.0（Swagger 用） |
| `test_serializers.py` | Serializer 基本テスト |
| `test_urls.py` | URL 解決テスト |
| `test_views.py` | View / パス検証テスト |
| `conftest.py` | pytest 用設定 |
| `__init__.py` | パッケージ化 |

例: `generated/product/` → `product_serializers.py` / `product_views.py` / `product_handlers.py`

業務ロジックは `{prefix}_handlers.py` の関数本体を Service / Selector 呼び出しに差し替えてください。  
既存 Enum を参照する生成コードは、実行時にそのモジュール（例: `common.util.Consts`）が import できる環境で動かしてください。

## 5. OpenAPI 生成（Swagger 用）

### ApiSpec YAML から OpenAPI のみ

```powershell
md-drf-codegen generate generated-specs\product-api.yaml --target openapi
```

出力（省略時）:

```text
generated-specs/product-api.openapi.yaml
```

### Markdown から一括

```powershell
md-drf-codegen build examples\product.md --target openapi --force
```

### Swagger で確認

1. [Swagger Editor](https://editor.swagger.io/) を開き、`*.openapi.yaml` または `generated/product/openapi.yaml` をインポート（File → Import file）
2. または Docker（任意）:

```powershell
docker run -p 8080:8080 -e SWAGGER_JSON=/spec/openapi.yaml -v ${PWD}/generated/product:/spec swaggerapi/swagger-ui
```

ブラウザで `http://localhost:8080` を開きます。

詳細は [README.md](../README.md) の「OpenAPI / Swagger」を参照してください。

## 6. 一括実行（最短手順）

`build` で extract → validate → generate をまとめて実行します。

```powershell
md-drf-codegen build examples\product.md --target all --force
```

段階的に実行する場合:

```powershell
# Phase 1: ApiSpec YAML のみ
md-drf-codegen build examples\product.md --target yaml

# Phase 2: Serializer まで
md-drf-codegen build examples\product.md --target serializer --force

# Phase 3: OpenAPI のみ
md-drf-codegen build examples\product.md --target openapi --force

# Phase 4: すべて（DRF + openapi.yaml）
md-drf-codegen build examples\product.md --target all --force
```

完了後の主な出力（`product.md` の場合）:

```text
generated-specs/product-api.yaml
generated-specs/product-api.openapi.yaml   # build --target openapi 時
generated/product/                         # build --target all / serializer 時
  ├── product_serializers.py
  ├── product_handlers.py
  ├── product_views.py
  ├── product_path_validators.py
  ├── openapi.yaml
  ├── urls.py
  └── test_*.py ...
```

## 8. 仕様変更時の再生成

1. `examples/product.md`（または対象 Markdown）を編集する  
   （Enum 追加時は `定数定義一覧` と型定義の `enum:` / `ref:` を更新）
2. `md-drf-codegen build examples\product.md --target all --force` を実行する
3. 次が更新される:
   - `generated-specs/product-api.yaml`
   - `generated-specs/product-api.openapi.yaml`（`openapi` ターゲット時）
   - `generated/product/` 配下の Python / `openapi.yaml`（`all` 時）

ApiSpec YAML は人間がレビュー・編集できる中間成果物です。Markdown を変えず YAML だけ直す場合は `generate` を直接実行できます。

## トラブルシュート

| 症状 | 確認点 |
| --- | --- |
| `MissingSectionError` | `## API一覧` / `## 型定義` があるか |
| `MissingColumnError` | 新形式: `必須` / `Nullable`。旧形式: `カテゴリー` / `任意` |
| パスパラメータ関連エラー | `{productId}` を使うなら `## パスパラメータ` に同名の行があるか |
| `TypeReferenceError` | API の request/response 型が型定義に存在するか |
| Enum ref エラー | `ref:ClassName` が一覧に無い。`定数定義一覧` にクラスを追加するか `enum:` 値を書く |
| `Status.choices` が無い | 生成は標準 Enum 向け。`[(m.value, m.name) for m in Status]` 形式になっているか |
| ImportError（Consts 等） | 実行環境から `定数定義一覧` のパスが import できるか |
| `FILE_EXISTS_ERROR` | 再生成時に `--force` を付ける |
| `CHECK_FAILED` | `--check` で差分あり。`--force` で更新する |
| `md-drf-codegen` が見つからない | venv を activate したか、`pip install -e ".[dev]"` 済みか |
| Swagger に ApiSpec YAML を入れても表示されない | **OpenAPI ファイル**（`openapi.yaml` / `*.openapi.yaml`）を使う |
